T-Dongle Keyboard

Flash the firmware onto a LilyGO T-Dongle S3 straight from this page. Works in Chrome and Edge on desktop.

  1. Hold the button on the dongle while plugging it in, then release.
  2. Click Install and pick the serial port that appears.
  3. When it finishes, unplug and replug without touching the button.

This browser cannot talk to serial ports. Use Chrome or Edge on a desktop. This page has to be served over HTTPS.

After flashing

The screen shows a network name and password, both derived from the device MAC. Join that network and the page opens by itself, or go to http://192.168.4.1.

Flash from a terminal instead 
esptool --chip esp32s3 --port /dev/ttyACM0 write-flash 0x0 firmware.bin

The image stops before the filesystem partition, so saved payloads and settings survive an update.
